# katekyo-report

個人契約の家庭教師業務における、指導報告書の作成・送信を自動化するWebアプリケーションです。

## 背景・課題
毎回のオンライン授業後、Zoomの議事録を確認して保護者・生徒向けの定型フォーマットに書き直し、LINEで送信する作業に手間がかかっていました。この一連のフローを自動化・効率化するために開発しました。

## 主な機能・処理フロー
1. **議事録の取得**：Gmail API経由で、自分のアカウントに届いた最新のZoom議事録メールから本文を抽出
2. **報告書の自動整形**：抽出した本文と専用プロンプトをOpenAI API（ChatGPT）に渡し、定型の指導報告フォーマットへ整形
3. **LINE配信**：整形されたメッセージをLINE Messaging API経由で公式アカウントから発信

```text
[Gmail (Zoom議事録)] ──▶ [本文抽出] ──▶ [OpenAI API (定型フォーマットへ整形)] ──▶ [LINE Messaging API (公式アカウントから送信)]
